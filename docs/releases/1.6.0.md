## 1.6.0

### 新增

- 安装包 `WifiDirectTransfer-1.6.0-setup.exe`：按用户安装到 `%LOCALAPPDATA%\Programs\WifiDirectTransfer`，不需要管理员权限，保留便携 zip。
- 安装包包含开始菜单快捷方式、可选桌面快捷方式和标准卸载项；卸载时可选择是否删除设置和历史记录。
- 自动更新：安装版启动 20 秒后检查更新，发现新版本时提示下载，校验 SHA-256 后静默安装并自动重启。
- “更多设置”增加“启动时检查更新”（默认开启），“关于”增加“检查更新”按钮。
- 支持“跳过此版本”；便携版不自我更新，只提供下载页入口。

### 升级

- 从 1.5.0 或更早版本升级时，安装包会沿用原安装目录；设置、历史、信任设备和未完成传输都会保留。
- 首次从 zip 迁移到安装版时，请先退出正在运行的便携版，再运行安装包。

### 已知限制

- 安装包暂未代码签名，首次运行会触发 SmartScreen 提示，可选择“更多信息 → 仍要运行”。
- 安装器界面目前为英文；应用界面仍为中文。

### 兼容性

- 协议版本仍为 v4，与 1.5.0 / 1.4.x / 1.3.x / 1.2.x 文件传输互通。
- 自动更新只对安装版生效，便携版继续手动下载。

### 安装

1. 下载 `WifiDirectTransfer-1.6.0-setup.exe`。
2. 运行安装包，按向导完成安装。
3. 首次运行如出现 SmartScreen 提示，选择“更多信息 → 仍要运行”。

### 校验

Release 资产中包含：

- `WifiDirectTransfer-1.6.0-win-x64.zip` 及 `.sha256`
- `WifiDirectTransfer-1.6.0-setup.exe` 及 `.sha256`
- `latest.json`（自动更新清单）
