## 1.4.0

### 新增

- 设备身份：每台设备生成 ECDSA P-256 密钥，私钥保存在 Windows 用户密钥存储（CNG），不可导出。
- 首次配对：连接后双方交换 nonce、公钥和签名，派生相同的 6 位配对码；两端确认一致后才完成配对。
- 可信设备：以公钥 SHA-256 指纹识别设备，支持自动接受、可信设备管理窗口和取消信任。
- 信任状态交换：任一端未信任时，两端都会显示配对码，避免只有一端能够比对。
- 身份变化保护：名称或 Peer Id 匹配可信设备但公钥指纹变化时，拒绝连接并提示重新配对。
- 安全审计：新增 `audit.jsonl`，记录连接接受/拒绝/超时、身份验证、配对、信任增删、可信自动接受以及剪贴板和远程文本开关。
- 诊断导出包含审计日志。
- 设置新增“可信设备自动接受连接”，默认为开启。

### 变更

- 接收端拒绝或接收确认超时后，会完成并立即关闭传输握手以释放 PeerFinder 请求，然后保持等待广播，不重启 PeerFinder。
- 身份交换处理器在握手和接收循环启动前创建，避免早到的身份消息被丢弃。
- 发送端连接失败后清除本次使用的 `PeerInformation` 缓存，下次重试会重新发现对端。
- 协议版本仍为 v4，文件头仍为 v2；设备身份消息是 1.4+ 的可选扩展。

### 兼容性

- 与 1.3 / 1.2 / 1.1 对端文件传输互通。
- 1.3 及更早对端不支持设备身份交换，会回退到原有的接收确认流程，不显示配对码。
- 空文件夹仍需要两端 1.3+。
- 升级到 1.4 后，历史设备默认不受信任，需要重新配对。

### 安装

1. 下载并解压 `WifiDirectTransfer-1.4.0-win-x64.zip`。
2. 运行 `WifiDirectTransfer.App.exe`。
3. 首次连接时确认两端配对码一致，并按需勾选“信任此设备”。

### 校验

Release 资产中包含 `WifiDirectTransfer-1.4.0-win-x64.zip.sha256`。
