## 1.1.1

### 新增

- 深色模式：支持跟随系统、浅色、深色三种模式。
- 主题设置会在“更多设置”中持久化，切换后立即应用到已打开的窗口。
- Windows 原生标题栏同步切换深色/浅色。
- ComboBox、右键菜单、滚动条、进度条和 ToolTip 完成深色适配。

### 变更

- 主题颜色资源拆分为 `Light.xaml` / `Dark.xaml`，样式统一使用 `DynamicResource`。
- 高对比度模式尚未完整适配，当前会回退到浅色主题。

### 兼容性

- 协议仍为 v4，与 1.1.0 互通。
- 旧版本 1.0.x 仍不兼容。

### 安装

1. 下载并解压 `WifiDirectTransfer-1.1.1-win-x64.zip`。
2. 运行 `WifiDirectTransfer.App.exe`。
3. 在“更多设置 → 主题”中选择跟随系统、浅色或深色。

### 校验

Release 资产中包含 `WifiDirectTransfer-1.1.1-win-x64.zip.sha256`。
