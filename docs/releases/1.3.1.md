## 1.3.1

### 新增

- 传输历史增加“平均速度”和“耗时”列。
- 完成记录会保存本次传输耗时和平均速率。
- 诊断信息增加当前传输速率、对端单文件上限、空文件夹清单支持、发送队列项目和文件数、本次接收项目数和文件数。
- 高对比度模式使用系统高对比度颜色，文字、边框、选中行和提示框保持可读。

### 变更

- 主窗口最小宽度调整为 1000，详情面板宽度调整为 220，减少展开详情时队列表格过窄的问题。
- 传输历史窗口加宽，容纳平均速度和耗时列。
- 协议仍为 v4，文件头仍为 v2，传输行为不变。

### 兼容性

- 协议版本：v4。
- 文件头版本：v2。
- 与 1.2.x / 1.3.0：文件传输继续互通。
- 空文件夹需要两端 1.3+。

### 安装

1. 下载并解压 `WifiDirectTransfer-1.3.1-win-x64.zip`。
2. 运行 `WifiDirectTransfer.App.exe`。
3. 如需资源管理器右键发送，在“更多设置”中勾选“资源管理器右键发送”。

### 校验

Release 资产中包含 `WifiDirectTransfer-1.3.1-win-x64.zip.sha256`。
