## 1.2.0

### 新增

- 单文件上限从 2 GiB 提升到 16 GiB。
- 发送队列、当前发送文件和接收面板显示实时速率与预计剩余时间。
- 总体进度显示队列总速率和预计剩余时间。
- “更多设置”新增资源管理器右键菜单开关。
- 启用后，右键文件或文件夹选择“通过 Wi-Fi Direct 发送”，应用会打开并把路径加入发送队列。
- 应用已运行时再次右键发送，会把路径交给现有窗口，不启动第二个进程。
- 支持 `--send` 启动参数，便于“发送到”快捷方式或脚本调用。

### 变更

- 协议仍为 v4，文件头仍为 v2。
- 1.2 与 1.1.x 在 2 GiB 以内继续互通；超过 2 GiB 的文件需要两端都使用 1.2 或更高版本。连接后应用会按对端构建号自动限制发送上限。
- 大文件接收仍使用 `.part` / `.meta` 断点续传，磁盘空间预检使用 64 位字节数。
- 资源管理器右键菜单只注册当前用户（HKCU），不请求管理员权限。

### 未包含

- Windows 系统共享目标：未打包的 WPF 应用缺少 MSIX 包身份，无法注册 ShareTarget，暂不实现。
- 空文件夹保留：需要协议 v5，继续后置。
- 资源管理器多选时当前发送第一个项目；需要发送多个文件时请逐个操作或拖入窗口。
- Windows 11 中传统右键菜单项可能位于“显示更多选项”下。

### 兼容性

- 协议版本：v4。
- 文件头版本：v2。
- 与 1.1.x：2 GiB 以内互通；超过 2 GiB 需要两端 1.2+。
- 与 1.0.x：仍不兼容。

### 安装

1. 下载并解压 `WifiDirectTransfer-1.2.0-win-x64.zip`。
2. 运行 `WifiDirectTransfer.App.exe`。
3. 如需资源管理器右键发送，在“更多设置”中勾选“资源管理器右键发送”。

### 校验

Release 资产中包含 `WifiDirectTransfer-1.2.0-win-x64.zip.sha256`。
