## 1.1.0

### 新增

- 文件夹层级传输：发送端保留根目录名和子目录结构，接收端自动创建目录并显示相对路径。
- 队列控制：在当前块完成后暂停/继续，右键上移、下移或移除文件；已完成文件也可从队列移除。
- 自动重连：发送端在传输中断开时最多尝试 3 次重连，并重新入队未完成文件续传；手动断开不触发。
- 系统通知：连接请求、传输完成/失败和自动重连结果；点击通知恢复窗口，可在“更多设置”中关闭。
- 接收端启动扫描未完成传输时递归扫描子目录。

### 变更

- 协议升级为 v4，文件头升级为 v2；1.1 不再兼容 1.0.x，两台电脑必须同时升级到 1.1.0 或更高版本。
- 空文件夹暂不发送；文件夹中只要包含文件，目录层级会保留。

### 安装

1. 下载并解压 `WifiDirectTransfer-1.1.0-win-x64.zip`。
2. 两台电脑都运行其中的 `WifiDirectTransfer.App.exe`，不要与 1.0.x 混用。
3. 接收端点击“等待连接”，发送端扫描并连接。

### 校验

Release 资产中包含 `WifiDirectTransfer-1.1.0-win-x64.zip.sha256`，可用它校验下载的 zip。
