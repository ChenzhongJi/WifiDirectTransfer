## 1.3.0

### 新增

- 文件夹传输保留空文件夹。
- 只包含空文件夹的文件夹也可以发送。
- 传输队列改为顶层项目显示：文件夹一行，直接添加的文件一行，不展开文件夹内部文件。
- 文件夹行显示文件数、总大小、汇总状态和汇总进度；文件夹支持整组上移、下移和移除。
- 接收列表改为顶层项目显示：直接文件一行，文件夹一行，显示文件数、空文件夹数、总大小、最近接收时间和接收状态。
- 发送端同一队列内重复顶层文件夹自动使用 `docs (2)` 等目标路径，接收端分开落盘和显示。
- 空文件夹通过目录清单在文件之前发送，接收端自动创建。
- 发送队列显示“另含 N 个空文件夹”；只有空文件夹时显示“将创建 N 个空文件夹”。
- 接收端创建空文件夹后在状态栏提示创建数量。
- 队列运行中追加的空文件夹会在当前文件完成后补发。
- 自动重连会重新入队尚未发送的空文件夹清单。

### 变更

- 协议仍为 v4，文件头仍为 v2。目录清单使用 1.3+ 可选控制消息，不影响旧版文件传输。
- 1.3 与 1.2.x 在文件传输方面继续互通；对端低于 1.3 时不会保留空文件夹，并会给出提示。
- 目录清单限制单次连接最多 100,000 个空文件夹，路径继续使用 `SafeRelativePath` 校验。
- 空文件夹只会在两端都使用 1.3 或更高版本时保留。

### 未包含

- 滑动窗口传输：等两机实测吞吐后再决定是否单独做 1.3.1。
- Windows 系统共享目标：未打包的 WPF 应用缺少 MSIX 或稀疏包身份。
- 可信设备自动接受。
- CLI 和英文界面。

### 兼容性

- 协议版本：v4。
- 文件头版本：v2。
- 与 1.2.x：文件传输继续互通；空文件夹不会保留。
- 与 1.1.x：2 GiB 以内文件互通；空文件夹不会保留。
- 与 1.0.x：仍不兼容。

### 安装

1. 下载并解压 `WifiDirectTransfer-1.3.0-win-x64.zip`。
2. 运行 `WifiDirectTransfer.App.exe`。
3. 如需资源管理器右键发送，在“更多设置”中勾选“资源管理器右键发送”。

### 校验

Release 资产中包含 `WifiDirectTransfer-1.3.0-win-x64.zip.sha256`。
