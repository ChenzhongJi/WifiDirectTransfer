## 1.5.0

### 新增

- 窗口传输：两端都是 1.5+ 时，发送端使用 16 块滑动窗口，不再每 64 KiB 等待一次 ACK。
- 接收端每 4 块批量 Flush `.part` 并发送累计 ACK，降低磁盘和网络往返开销。
- 窗口满时发送端才等待累计 ACK，形成背压并限制内存占用。
- 大文件传输日志增加窗口大小、ACK 间隔、平均 ACK 等待和最大在途字节。
- 发送端遇到 E_INVALIDARG（过期 `PeerInformation`）时自动清除缓存、重新发现并重试一次；重试失败返回“对端信息已过期”，不再显示未知错误。

### 兼容性

- 协议版本：v4。
- 文件头版本：v2。
- 1.4 及更早对端自动回退到逐块停等 ACK，文件传输继续互通。
- 窗口传输需要两端 1.5+。
- 设备身份验证需要两端 1.4+；空文件夹需要两端 1.3+。

### 安装

1. 下载并解压 `WifiDirectTransfer-1.5.0-win-x64.zip`。
2. 运行 `WifiDirectTransfer.App.exe`。
3. 首次连接时确认两端配对码一致，并按需勾选“信任此设备”。

### 校验

Release 资产中包含 `WifiDirectTransfer-1.5.0-win-x64.zip.sha256`。
