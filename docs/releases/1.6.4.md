## 1.6.4

### Wi-Fi Direct 发现与连接

- 增加操作系统、AppUserModelID、前台状态和 PeerFinder 发现状态诊断，并提供独立发现探针。
- `FindAllPeersAsync` 返回 ERROR_CRC 时可使用 PeerWatcher 兜底；扫描异常会重启并重试，watcher 同步或异步失败不再被误报为“未发现设备”。
- 修复 PeerFinder 停止与连接建立之间的竞争；重启失败会保留具体错误并终止扫描。
- 后台展开拖入或选择的文件夹，减少大目录扫描期间的界面阻塞。

### 文件传输与续传

- 按消息类型限制帧大小；非法文件块会回传具体错误，日志轮转和接收事件 UI 编组得到修复。
- 修复队列计数器、整体速率统计、长文件名自动改名和剪贴板对端切换去重。
- 续传首个响应使用 10 分钟宽限，窗口 ACK 使用整体等待预算；不足一个窗口的续传尾部也能等待接收端重校验已有数据。
- `FileStart`、`FileChunk`、`FileEnd` 以及 `TransferError` 通知期间的本地取消不再误报失败或删除 `.part` / `.meta`。

### 安全与自动更新

- 设备身份验证强制 ECDSA P-256；不兼容的既有本机密钥会自动替换。
- 剪贴板图片限制压缩大小和解码后像素数，并拒绝非 PNG 远端图片。
- Release 的安装包初始 URL 和重定向仅接受白名单 HTTPS 主机；`WDT_UPDATE_FEED` 仅用于 Debug 本地测试。
- 更新下载按声明大小限流，安装前重新校验大小和 SHA-256；静默更新结束后会重新启动应用。
- AppUserModelID 初始化失败时提示并干净退出；注销、关机和关闭流程会取消传输并停止相关计时器。

### 兼容性

- 协议版本仍为 v4，与 1.6.3 及更早版本按既有规则互通。
- 从 1.6.3 升级会保留设置、历史记录、可信设备和未完成传输。
