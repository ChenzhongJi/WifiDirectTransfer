## 实现备注

- T5：接收端在 SHA-256 校验通过且正式文件落盘后发送 `FileVerified`（携带接收端计算的摘要）；发送端收到匹配摘要后才把文件标记为完成，队列随后处理下一个文件。校验失败或落盘失败时接收端发送 `TransferError`，不再让发送端空等。
- W1：数 MB 以上的剪贴板图片可能不会出现在 Windows 剪贴板历史（Win+V）中，但仍保留在当前剪贴板里，直接 Ctrl+V 粘贴正常。同步是否成功应以接收端状态栏和日志为准，不能以 Win+V 是否显示判断。
